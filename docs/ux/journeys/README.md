# User journeys

Text journey maps for the five highest-stakes flows on the platform. Each follows the same skeleton:

1. **Persona + trigger** — who is the user, why are they here
2. **Steps** — what they do, what they see, what they think, what could go wrong
3. **Signals** — the analytics rows, audit-log entries, or DB state changes that prove they succeeded (or didn't)
4. **Failure modes** — known + suspected pain points
5. **Open questions** — what we don't know yet (research backlog)

These journeys back the three outcomes in `docs/ux/charter.md` — each maps to one or two outcomes and provides the qualitative texture the charter's metrics can't capture alone.

Stubs have an outline + open questions so when bandwidth lands, the framing is already done.
